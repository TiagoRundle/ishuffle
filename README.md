iShuffle is an iOS app intended to simulate how people can use a standard deck of cards in real life. This means that there are no card game rules hard coded into the app, allowing the user to play any game that utilizes standard decks. Features include shuffling, player hands, free movement and flipping of cards in the playing area, multiple decks, betting with chips, and a text chat. It uses Firebase Realtime Database to sync updates between up to 8 devices for multiplayer. iShuffle was developed independently by me in 2023 over the course of several months. Other tools and frameworks used include Xcode, Sourcetree, and Bitbucket. There was no use of AI during the development process. The resources used for learning and implementation were official documentation, Swift UI videos, and Stack Overflow. iShuffle was temporarily deployed for extensive debugging and testing, though it was never published on the App Store.
